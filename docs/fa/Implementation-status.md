# وضعیت پیاده‌سازی

README قرارداد نسخهٔ اول را شرح می‌دهد. نسخهٔ فعلی قواعد دامنه و پایهٔ HTTP و schema تأییدشدهٔ CBS09 را دارد. handler مالی هنوز آماده نیست و هر چهار route مالی 503 می‌دهند.

آخرین شواهد ۲۴۰ تست مستقل از زیرساخت و ۹۴ تست واقعی SQL Server بدون failure، error یا skip است. [schema و راهنما](Schema.md)، [نقشهٔ راه](Roadmap.md) و [شواهد HTTP](HTTP-adapter-evidence.md) را ببینید. گام بعد نگاشت entity، fixture افتتاحیه و موجودی committed است. schema و health، تکمیل نسخهٔ مالی را ثابت نمی‌کنند.
